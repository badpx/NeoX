# ADR 0001：三个独立契约取代"唯一 IR"

- 状态：已接受（2026-10-24）
- 背景：初版方案把运行时结构、序列化格式与稳定接口压缩为单一"IR 契约"，
  并要求"先冻结 IR schema"。评审指出：适合本地快速遍历的布局未必适合跨
  进程传输；公开 API、资源生命周期、Shader 接口同样是契约，不能都压缩成
  一个 IR 问题。
- 决定：拆分为 SD（图形语义）、ER（执行表示，后端私有）、CAP（捕获/传输
  格式）三个契约，各自独立演化。正常本地绘制不经过序列化。第一阶段只冻结
  双实现验证过的语义最小子集。
- 后果：CAP 成为可选旁路，GL 后端零成本获得录制/回放能力（已验证）；
  语义规范的演化节奏不受格式兼容性拖累。代价是三份契约需要分别维护。
