# ADR 0006：NeoX-Text v0 范围——A8 覆盖率图集先行，SDF/MSDF 留待核心扩展

- 状态：已接受（2026-10-26）
- 背景：设计文档 §8 规定核心只接受已定位字形，字体解析/shaping/回退/布局
  属独立的 NeoX-Text 模块；MSDF、位图图集、CPU 光栅化轮廓是并列可选的
  字形绘制表示。首次实现需要决定 v0 的边界。
- 决定：
  1. **v0 = A8 覆盖率动态图集**：字形缓存 + shelf 装箱 + 增量上传，直接
     对接核心现有的 `neox_draw_glyphs`（A8 遮罩语义），核心零改动。
  2. **SDF/MSDF 推迟**：其渲染语义（采样距离场 → smoothstep 重建边缘）
     与 A8 遮罩不同，需要核心扩展——glyph run 增加图集语义标志、三后端
     shader 变体、规范 §8 修订。作为独立迭代处理，避免把两个变化量揉在
     一个 PR 里。
  3. **字体解析依赖 stb_truetype**（vendored 于 `third_party/`）：属设计
     §9 的"模块必需（可裁剪）"层级；核心零依赖不变，`NEOX_WITH_TEXT=OFF`
     可整体裁掉。HarfBuzz 级复杂整形暂以"简化 shaping"（kerning、贪心
     断行、CJK 逐字可断）替代并在文档中明示边界。
- 后果：文字能力以最小风险落地并保持三后端逐位一致；SDF/MSDF 迭代时
  将触发规范 §8 的首次实质性扩展（绘制表示的语义枚举化）。
