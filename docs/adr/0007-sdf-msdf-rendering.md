# ADR 0007：距离场渲染模式（SDF/MSDF）的 API 形态与一致性期望

- 状态：已接受（2026-10-26）
- 背景：ADR 0006 预留了本次迭代。SDF/MSDF 的采样语义（距离场 → 重建覆盖率）
  与 A8 遮罩不同，需要核心扩展；同时需要决定：API 形态、编码约定、跨后端
  一致性期望。
- 决定：
  1. **API 形态**：新增 `neox_draw_glyphs_ex` + `neox_glyph_style`
     （atlas_mode / dist_range_px / softness），原 `neox_draw_glyphs` 保留为
     COVERAGE 默认的等价转发。绘制调用级标志而非纹理属性——同一张图集的
     语义在绘制点显式化，错误更容易定位。
  2. **编码约定**：`d = (0.5 − v/255)·dist_range_px`，重建
     `cov = smoothstep(+w/2, −w/2, d·s)`；s（局部→输出缩放因子）取 2×2
     线性部分的奇异值平均，Soft 在采样处计算，GL/Metal 由 CPU 算好传
     uniform——三端同式（规范 §8.2）。
  3. **一致性期望放宽**：距离场重建含 GPU 浮点运算，跨后端按 §9 容差
     （实心区精确 + 边界 ≤32/255 + 单调），不承诺逐位——§9 容差模型的
     首次真实使用。（实测结果优于预期：三后端饱和区逐位一致。）
  4. **MSDF 生成自实现**（stb 不提供）：轮廓提取（stbtt_GetGlyphShape）
     → 拐角（方向差 >60°）边着色循环 R/G/B → 逐像素分通道最小有向距离
     （符号由覆盖率位图判定）。简化点：用真有向距离而非 msdfgen 的伪距离，
     尖角内侧可略圆；测试不对尖角像素断言。
  5. **质量断言制度化**：`check_sdf_quality` 用数值证明"分辨率无关"——
     4x 放大下覆盖率模式边缘最大阶跃 49 vs SDF 17（阈值 sdf < cov/2）。
- 后果：文字渲染具备分辨率无关能力；`dist_range_px` 生成/绘制不匹配定性为
  静默语义错误，由模块侧（`nx_atlas_create_ex` 与 `nx_text_draw_ex` 成对
  携带 style）管理。遗留：msdfgen 完整伪距离与更精细的拐角处理属未来优化。
