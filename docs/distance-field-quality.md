# 距离场的独立质量证据与资产契约

距离场可缩放，不意味着任意放大都能恢复准确的矢量轮廓。跨后端一致性、
轮廓准确性和视觉平滑度是三个不同指标。尤其不能通过降低边缘阶跃就证明
“分辨率无关”；模糊同样能降低阶跃。

## 可复现样本

`tests/fixtures/make_quality_font.py` 只用 Python 标准库生成原创微型 TrueType
夹具：尖三角、带矩形孔洞的轮廓、50/1000 em 细竖笔画。二进制夹具入库，
日常 CTest 不需要 Python、系统字体、网络或额外字体依赖。
`test_distance_quality` 使用公开 Text API，在 32 px 字号生成覆盖率/SDF/MSDF
图集，再以 0.5、1、2、4 倍及 4×1 非均匀比例绘制。

参考图由测试中的独立解析区域不等式逐输出像素进行 16×16 子采样得到，
不调用 NeoX 几何光栅器、stb 位图或距离重建公式。参考本身有子采样误差，
不是连续面积积分的无限精度证明。测试记录归一化 L1（覆盖率绝对误差总和
除以参考形状面积）、相对面积误差和最大单像素误差，并另检查孔洞和实心内部。

macOS Soft 初始测量，五种变换中的最大归一化 L1：

| 样本 | 覆盖率图集 | SDF | 内置简化 MSDF |
|---|---:|---:|---:|
| 尖三角 | 6.91% | 2.02% | 7.72% |
| 孔洞 | 9.37% | 2.63% | 7.84% |
| 细笔画 | 33.11% | 11.43% | 24.48% |

这些样本中 SDF 的整体误差较小；MSDF 没有显示优势。SDF 和 MSDF 的个别
放大尖角/端点像素仍可出现 100% 覆盖率误差。不能仅凭低平均误差宣称尖角正确。
测试阈值按模式/样本固定，作为当前版本的回归包络，并非所有字体的质量承诺。
运行 `ctest -R distance_quality -V` 可获得每个后端、样本、变换的完整测量。

## 内置生成器边界

内置 SDF 使用 stb 的单通道距离场。内置 MSDF 使用简单循环边着色、固定次数
曲线细分和覆盖率位图阈值决定符号，没有完整伪距离、轮廓接缝协调或误差校正。
尖角通道不一致、薄笔画的符号判断、缩小导致的信息丢失，以及非均匀变换下的
方向无关重建都可能产生误差。将其定位为实验能力；高质量资产宜在应用的离线
流程中生成并单独验收。复杂字体、曲线、重叠轮廓与极端缩放需要更多样本，
本次三种解析形状不覆盖这些情形。完整替换 MSDF 生成器属于后续独立工作。

## 离线资产接入

核心接受调用方已经解码的像素，不引入 PNG 解码器、字体解析器或资产生成工具。
可将离线图集导出为原始 A8/RGBA 字节或 C 数组，同时保存以下元数据：

- 像素尺寸、行距、左上原点、每个 glyph 的源矩形及基线偏移；
- SDF 用 A8；MSDF 用 RGBA8_DATA，RGB 是线性数据，alpha 被忽略；
- 完整距离跨度 `R`、生成字号/单位和 padding。编码值越小表示越在形状内部，
  `d=(0.5-u)*R`。若工具输出“内部较大”的同跨度编码，逐通道使用 `255-v`
  转换；若工具声明的是单侧距离范围，先确认完整跨度是否为其两倍；
- PNG 的 sRGB 标记不能触发对 RGB 距离数值的色彩变换；若工具采用左下原点，
  先翻转像素与源矩形坐标。边界零距离约为 127.5，内置 128 编码存在半 LSB 偏移。

通过 `neox_texture_create` 上传原始像素，再使用 `neox_draw_glyphs_ex`，设置
`atlas_mode` 和匹配的 `dist_range_px=R`。源矩形的宽高也定义默认局部绘制尺寸，
用帧变换表达缩放。核心不读取字体 advance/kerning 元数据，应用或 Text 之外的
排版模块负责字形定位。此路径绕过内置生成器，但仍受有限分辨率、采样与重建
算法限制；外部工具的默认编码和 NeoX 不应被假定为天然兼容。

量化、插值和 smoothstep 都会改变结果。规范使用 `t=clamp(d*s/softness+0.5)`、
`coverage=t*t*(3-2*t)`；距离已经乘过缩放因子时不得重复乘。非均匀缩放固定取
两奇异值平均，不使用隐含的后端自选公式。
